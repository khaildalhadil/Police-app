# نظام إدارة بيانات القضايا والوثائق — شرطة عُمان السلطانية

تطبيق Next.js لإدارة بيانات المتهمين والقضايا:

- **الأشخاص** مفتاحهم الأساسي هو **الرقم المدني** ولا يتكرر؛ لإضافة قضية أخرى لنفس الشخص افتح سجله واختر «قضية جديدة لنفس المتهم».
- **القضايا**: التهمة، منطوق الحكم، تواريخ الحجز وتمديد الحجز والإفراج (يظهر الشخص «مُفرج عنه» عند حلول تاريخ الإفراج).
- **المواعيد وجرس التنبيه**: تمديد الحجز، الإفراج، المستشفى، المحكمة، النيابة العامة، القضاء العسكري، أخرى.
- **المتصلين بهم** (صفحة مستقلة): الرقم المدني وجنسية المطلوب، الاسم الثلاثي، الهاتف، الصلة، التاريخ والوقت، موقع المطلوب، رد / لم يرد.
- **السجناء** (صفحة مستقلة): الاسم الثلاثي، تاريخ الحبس، تاريخ الانتهاء، نوع القضية، مكان التوقيف، الملاحظات؛ ويظهر تاريخ الانتهاء في جرس التنبيه قبل أسبوع.
- **الإجازات الإدارية للأفراد** (صفحة خاصة بالمسؤول برقم سري): الرقم العسكري، الاسم الثلاثي، الرصيد، المتبقي، الملاحظات؛ عند الخصم من الإجازة يُحسب المتبقي تلقائياً.
- **مرفقات القضية** وصورة المتهم، البحث، الطباعة، والنسخ الاحتياطي.

> لا توجد قاعدة بيانات خادم حالياً: البيانات محفوظة في متصفح الجهاز (IndexedDB).
> خذ «تصدير نسخة احتياطية» بشكل دوري. السجلات المحفوظة في النسخة القديمة من النظام تنتقل تلقائياً عند فتحه من نفس الموقع.

## التشغيل

```bash
npm install
cp .env.example .env.local   # ثم ضع اسم المستخدم وكلمة المرور والرقم السري للمشرف
npm run dev
```

ثم افتح http://localhost:3000

## متغيرات البيئة

| المتغير | الاستخدام |
| --- | --- |
| `APP_USERNAME` | اسم المستخدم لتسجيل الدخول |
| `APP_PASSWORD` | كلمة المرور لتسجيل الدخول |
| `SUPERVISOR_PASSWORD` | الرقم السري للمسؤول لفتح صفحة الإجازات الإدارية |

## النشر

الموقع منشور على Vercel ومربوط بفرع `main`، فأي رفع عليه يُنشر تلقائياً. أضف المتغيرات أعلاه في إعدادات المشروع (Environment variables)؛ بدون `APP_USERNAME` و `APP_PASSWORD` لن يتمكن أحد من الدخول، وبدون `SUPERVISOR_PASSWORD` تبقى صفحة الإجازات مقفلة.
